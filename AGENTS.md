Security is the highest priority in this repository.

For every change:

- Preserve API compatibility unless explicitly requested otherwise.
- Prefer the smallest secure and testable change.
- Do not expose or log secrets, passwords, OTPs, JWTs, credentials, or sensitive internal errors.
- Use relevant Superpowers skills and sub-agents when useful; do not wait indefinitely for stalled agents.
- Verify before claiming completion.

After meaningful changes, explain what changed, why, how it works, security and maintainability benefits, tradeoffs or compatibility impact, and checks run.
